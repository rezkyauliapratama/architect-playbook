## ✨ Features

- ✅ **Account Inquiry** - Validate and retrieve account information
- ✅ **BI-FAST Transfer** - Simulate inter-bank real-time transfers
- ✅ **Transaction Status** - Query transaction progress
- ✅ **Idempotency** - Prevent duplicate transactions
- ✅ **Admin Dashboard** - Transaction management and statistics
- ✅ **Rate Limiting** - Protect against abuse
- ✅ **Mock Scenarios** - Simulate success, failure, timeout scenarios
- ✅ **Structured Logging** - Zerolog for production-ready logging
- ✅ **Docker Support** - Containerized deployment
- ✅ **PostgreSQL** - Persistent storage with proper indexing
